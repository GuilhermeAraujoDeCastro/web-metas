# Créditos

Projeto desenvolvido por Guilherme Araújo de Castro.

## Bibliotecas e serviços de terceiros

- Firebase (Authentication e Firestore), da Google, para login e banco de dados
- Chart.js, para o gráfico de evolução do valor guardado em cada meta
- html2canvas, para exportar o card de meta concluída como imagem
- API oficial da Unsplash, para a busca de imagens ao criar ou editar uma meta
- esbuild, para empacotar o JavaScript no build de produção
- javascript-obfuscator, para ofuscar o código empacotado antes do deploy
- Netlify, para hospedagem, build e a função serverless que protege a chave da Unsplash

Cada uma dessas bibliotecas segue sua própria licença original, independente da licença deste repositório. As fotos retornadas pela busca de imagens pertencem aos seus respectivos fotógrafos na Unsplash, com crédito exibido junto de cada resultado.
